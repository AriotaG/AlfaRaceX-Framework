# Feature Parity Matrix — 25 settembre 2026

BACCAble `DOC` significa descritto nel manuale V4.7, non osservato in questa sessione.
`NV` significa non verificabile con le fonti recuperate. I test citati sono host:
nessuna riga riceve VERIFIED ON HARDWARE o VERIFIED AGAINST BACCAble.

Categorie adottate: VERIFIED SOFTWARE (solo il caso testato), VERIFIED AGAINST
BACCAble, VERIFIED ON HARDWARE, IMPLEMENTED BUT NOT HARDWARE-VALIDATED, PARTIAL,
EXPERIMENTAL, DISABLED, BROKEN, MISSING. `I-NHV` sotto abbrevia IMPLEMENTED BUT NOT
HARDWARE-VALIDATED. I test automatici non trasformano I-NHV in validazione veicolo.
